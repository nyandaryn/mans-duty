# MANS DUTY — Linux FPS / 0.5.3

Нативний прототип на Godot 4.5.1, GDScript, Compatibility / OpenGL 3.3. Український інтерфейс. Linux x86_64; інтернет під час гри не потрібен.

## Запуск

У `~/Documents/Mans_Duty/` запустіть `./play.sh` або `bash play.sh`. Двигун включено; тримайте `kvartal.x86_64`, `kvartal.pck` та скрипт поруч. Проєкт для редактора: `source/project.godot`. Налаштування зберігаються в Godot `user://settings.cfg`.

## Карти та спорядження

- Місто 96×96 м: шість будинків із доступними мебльованими першими поверхами, 24 кімнати, двори, транспорт і руйнування. Верхні поверхи поки недоступні.
- Посадка 192×192 м: густий ліс, високий підлісок, звивиста стежка, земляні насипи та два польові сховки. Дерева продовжуються за межами ігрової зони; відкриті поля прибрано. Насипи над землею — це ще не викопані траншеї.
- Зачистка від 10 ботів. Поверніться до старту та натисніть Enter для завершення. Автоматичного повідомлення про останнього вбитого немає.
- АК-74М / M16A2 та ПМ / Beretta M9. Власні моделі, записані звуки-замінники; точні джерела в `assets/AUDIO-CREDITS.md`.
- Сім комплектів: MM14, цифровий лісовий, MTP, два міські та два снайперські. Власні стилізації без точного відтворення офіційних тканин. Одяг не змінює бронезахист.
- Виявлення залежить від відстані, відкритих частин тіла, кольору фону, тіні, рослинності, руху та стрільби. Поблизу камуфляж не робить невидимим.

## Керування

| Клавіша | Дія |
|---|---|
| WASD / миша | Рух / огляд |
| ЛКМ / ПКМ | Вогонь / прицілювання |
| Утримувати R + 1 / 2 / 3 | Обмін магазина з обраним підсумком |
| I | Оглянути патронник без викидання набою |
| T | Оглянути встановлений магазин |
| Утримувати T + 1 / 2 / 3 | Оглянути магазин у підсумку |
| V | Пересмикнути затвор; наявний набій викидається |
| B / 1 / 2 | Режим вогню / автомат / пістолет |
| Shift / Ctrl / Z | Біг / присісти / лягти |
| Space | Стрибок |
| Q / E | Нахил ліворуч / праворуч |
| C у присіданні | Виглянути над укриттям |
| Alt + Q / E / C | Висунути автомат без голови, стріляти без прицілу |
| H | Універсальна аптечка: 6 секунд, 2 на матч |
| Enter біля старту | Завершити операцію |
| Esc / F11 | Пауза / повний екран |
| F8 | Дебаг: безсмертя й поповнення магазинів при обміні |

Для пістолета доступні тільки слоти 1 і 2 на поясі. Поза оглядом R без номера не виконує обмін. Під час огляду, коли магазин уже в руці, R відразу запускає пришвидшену перезарядку. Для оглянутого магазина з підсумка використовується саме цей магазин; після огляду встановленого магазина R обмінює його зі слотом 1.

## Магазини й зворотний зв’язок

Автомат має 4 магазини: один у зброї, три на плитоносці. Пістолет — 3: один у зброї, два на поясі. Боти також мають обмежений запас. Перший патрон береться зі стартового магазина: АК починає з 29+1, ПМ із 7+1. Патронник незалежний від магазина.

R+номер виймає поточний магазин, повертає його в обраний слот, дістає звідти інший, вставляє та за потреби досилає набій. Неповний магазин зберігає свій залишок. Переривання дією або пораненням зберігає вже виконані кроки; повторний обмін продовжує їх. Лише F8 поповнює магазин при обміні.

Огляд показує верхній набій або подавач. АК має візуальний індикатор повного магазина, пістолетні магазини — контрольні отвори; M16 оглядається зверху. Це геометричні підказки, а не числовий лічильник. Гільзи та цілі викинуті набої залишаються на карті до кінця матчу; підбирання поки немає.

HUD не показує кількість патронів, стан патронника, підтвердження влучань чи кількість живих противників. Результати доступні після завершення операції. Видимі кров, реакції на поранення та рухи персонажів.

## Поранення, боти й звук

Окремі анатомічні зони й бронеплити, травми кінцівок, кровотеча, падіння, кров на одязі/землі та короткі бризки при влучанні. Подробиці й межі моделі — у `WOUND-MODEL.md`. Універсальна аптечка повністю лікує, але не ремонтує броню; лікування займає час і переривається новим пораненням.

Боти мають прицілювання, стрільбу з коліна, укриття, обмін приблизним контактом, реакції на поранення, самолікування та перезарядки. Звук пострілу дає їм приблизний напрямок, не точну позицію за стіною.

Крики при влучанні — записаний голос із просторовим затуханням і затримкою між повтореннями. Миттєво смертельне влучання не запускає новий крик. Біль сильніше затемнює центр і краї екрана. Тривала стрільба поступово додає дзвін і приглушення слуху, що зникають після припинення стрільби. Гучність керується загальним повзунком; пауза зупиняє ефекти. Власні постріли гучніші за віддалені.

## Межі прототипу та перевірка

Моделі, карти й анімації процедурні low-poly. Камуфляж оцінюється за палітрою, фоном і променями до частин тіла, а не аналізом екранного зображення. Немає повної акустики відбиттів і проходження звуку крізь стіни. Поранення та слух — ігрові спрощення, не медична модель.

Перевіряється headless-сценаріями `tests/test_*.gd` та графічними переглядами 1280×720 на RX 550. Для слабких відеокарт можна вимкнути тіні. Ліцензія двигуна: MIT; ліцензії аудіо в `assets/AUDIO-CREDITS.md`. Збірка не використовує завантажену модель Sketchfab: геометрія зброї створена в проєкті.

## Темп вогню 0.5.1

АК-74М: 600 пострілів/хв, інтервал 0,100 с. Стартові 30 набоїв вистрілюються приблизно за 3 с (між першим і тридцятим — 29 інтервалів, 2,9 с). M16A2: 800 пострілів/хв усередині черги з трьох, інтервал 0,075 с; без автоматичного повторення черг при утриманні спуску. Орієнтир: https://www.moore.army.mil/infantry/DoctrineSupplement/ATP3-21.8/PDFs/fm3_22x9.pdf (діапазон M16A2 700–900).

ПМ і M9 — один постріл на натискання. Для швидких повторних натискань ігрові мінімальні інтервали відповідно 0,12 і 0,10 с; це налаштування симуляції циклу, не паспортна автоматична скорострільність. Практичний темп залежить від натискань і повернення прицілу.

Таймер переносить залишок часу між тактами й не накопичує борг пострілів у спокої. Боти використовують той самий інтервал АК усередині черги; між чергами зберігають тактичні паузи.

## Огляд і перезарядка 0.5.3

Огляд магазина триває 2,1 с замість 3,8; патронника — 1,8 с. Вікно переходу в перезарядку відкривається після діставання, до повернення магазина (підказка R у рядку дії). Підготовлений магазин із підсумка скорочує решту обміну до 1,75 с; уже вийнятий зі зброї — до 2,25 с, порівняно зі звичайними 3,2 с. За порожнього патронника додається досилання.

Рука йде до магазинової шахти для T, до відповідного з трьох нагрудних підсумків для T+1/2/3, або до одного з двох поясних пістолетних підсумків. Перехід із огляду не повертає магазин назад перед повторним діставанням. При скасуванні розпочатої перезарядки зберігаються всі магазини, залишки й виконані етапи.
