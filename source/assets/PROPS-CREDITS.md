# External prop assets

## Ammo Box — DanKit / Poly Haven

- Original: https://polyhaven.com/a/ammo_box
- License: CC0 1.0, https://polyhaven.com/license
- Author attribution: DanKit.
- Downloaded 2026-11-12 using https://api.polyhaven.com/files/ammo_box .
- Files: `props/ammo_box/`, glTF plus original 1K PBR textures.
- Each original file was checked against the MD5 returned by the provider API.
- Use: one environmental supply crate beside the insertion point. It is not
  a backpack item. Carryable ammunition uses original paper packet meshes.

The backpack, rangefinder, paper packets, straps, tape and first-person
field animations are original procedural game assets, not third-party scans.

Other suitable sources found, not imported: Poly Haven Binoculars by Derek
Wight (CC0, https://polyhaven.com/a/binoculars). A binocular model was not
substituted for a laser rangefinder; they are different devices.
